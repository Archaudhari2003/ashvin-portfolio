## 📌 Overview

The **TryHackMe Pre-Security** path is designed to build the technical foundation required before moving into more advanced cybersecurity topics.

I used this learning path to strengthen my understanding of how computers, operating systems, software, networks, the web, and basic security concepts work together.

The path combines structured lessons with practical, browser-based exercises, making it useful for turning theoretical concepts into hands-on understanding.

---

## 🎯 Learning Objectives

My main goals while working through the path were to:

* Build stronger computer fundamentals.
* Understand how operating systems work.
* Learn basic Linux and Windows concepts.
* Understand software and programming fundamentals.
* Strengthen networking knowledge.
* Understand how the web and Internet services work.
* Learn foundational cybersecurity concepts.
* Develop a habit of learning through practical exercises.

# 🔐 1. Introduction to Cyber Security

The introductory section establishes why technical foundations are important before attempting more advanced security work.

I learned about the relationship between:

* Offensive security
* Defensive security
* Cybersecurity careers
* The technologies that security professionals need to understand

The main takeaway was that cybersecurity is not limited to attacking systems. Understanding how systems work is equally important when protecting and monitoring them.
